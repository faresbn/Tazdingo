Forever runs the modern game client (interface 16001), so addons made for Classic Era or Anniversary won't load: install the version marked for Forever. On CurseForge, filter by game version 1.60.1 or look for files ending in "-forever". As in the modern game, addons can show combat information but can't act on it for you.

| Addon | What it's for | Forever version | Source |
|---|---|---|---|
| Questie | Quest objectives on the map | Listed | [foreverchanges.pro](https://foreverchanges.pro/addons) |
| RestedXP | Levelling route guide | Listed | [metammo.com](https://metammo.com/guides/wow-forever-addons-restedxp-questie-setup) |
| Auctionator | Auction House searching and scanning | Listed | [foreverchanges.pro](https://foreverchanges.pro/addons) |
| Details! | Damage and healing meter | Listed | [foreverchanges.pro](https://foreverchanges.pro/addons) |
| DBM, BigWigs | Boss timers and warnings | Listed | [foreverchanges.pro](https://foreverchanges.pro/addons) |
| Leatrix Plus, Leatrix Maps | Quality-of-life tweaks; fuller world map | Listed | [foreverchanges.pro](https://foreverchanges.pro/addons) |
| Bagnon, Baganator | Combined bags | Listed | [foreverchanges.pro](https://foreverchanges.pro/addons) |
| Plater | Nameplates | Listed | [foreverchanges.pro](https://foreverchanges.pro/addons) |
| TomTom | Waypoints and arrow | Listed | [foreverchanges.pro](https://foreverchanges.pro/addons) |
| Bartender4 | Action bars | Listed | [foreverchanges.pro](https://foreverchanges.pro/addons) |
| WeakAuras | Custom alerts | **No Forever version.** Forks exist: [ForeverAuras](https://addons.wago.io/addons/foreverauras); another fork's combat-log triggers reportedly never fire | [mmonster.co](https://mmonster.co/wow-forever/guides/addons/weakauras-forever) |
| TradeSkillMaster | Auction House and crafting automation | **Unclear:** sources disagree on whether it works | [mmonster.co](https://mmonster.co/wow-forever/guides/addons/tradeskillmaster) |

Status is as reported before launch. Check each addon's own page once the game is live.
