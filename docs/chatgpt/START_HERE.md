## Non-negotiable boundaries

- Tazdingo content is dated, source-bound evidence. An edit or publication is not a new in-game verification. Check the target game/build, market and observation time. Never label Beta evidence as release-tested.
- Public pages and feeds must provide the reference evidence needed by shared-project members, even if contributors cannot inspect the processing tools or access authenticated writes. A reader failing to retrieve a page should be told that, not fed an invented result.
- Public submissions may include original files. Do not submit private information or names without suitable permission. Do not execute uploaded Lua.
- Respect the current verified processing/review flow. A received submission is not committed, and a commit is not automatically deployed. Inspect real receipts and the published site before claiming publication.
- Changing the route map does not supersede the shared project's evidence, safety or privacy rules. When a linked procedure or tool is missing, disclose that instead of improvising a write.
